# sendSms 메서드 코드 분석

## 1. 개요

`sendSms`는 SMS/MMS를 **직접 발송하지 않고**, 발송할 데이터를 DB에 등록하는 메서드이다.
실제 발송은 SMS 업체의 Agent 프로그램이 DB 발송 테이블을 조회하여 처리하는 **DB 연동형(Agent) 방식**으로 추정된다.

```
[웹 애플리케이션] → DB 발송 테이블 INSERT
                          ↓ (주기적 조회)
                [SMS 업체 Agent] → 통신사/중계 서버 → 수신자
```

> 실제 발송 테이블은 `FN_TB_SMS` 펑션 소스를 확인해야 정확히 알 수 있다.
> 펑션명의 `EM_MMT_FILE`로 보아 `EM_SMT_TRAN`(단문), `EM_MMT_TRAN`(장문/MMS) 계열 테이블을 사용할 가능성이 높다.

## 2. 처리 흐름

| 단계 | 처리 내용 | 호출 대상 |
|---|---|---|
| 1 | 첨부파일을 서버 디스크에 저장 (`APPEND_FILE_DIRECTORY/SMS/yyyyMM/`) | - |
| 2 | 첨부파일 정보 DB 등록 | `FN_TB_EM_MMT_FILE` |
| 3 | 수신자별 SMS 데이터 등록 | `FN_TB_SMS` |
| 4 | 업무코드(`smsBizCd`)가 10/20/30/40/60이면 고객 활동 이력 등록 | `FN_TB_CUST_ACTIVE` |
| 5 | 결과 반환 (성공 `00`, 실패 `99` + 메시지) | `jsonView` |
